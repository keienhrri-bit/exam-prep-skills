# 讲题（二）：报告之后，订正第 3 问

> 合成对话，演示 `kaoyan-tutor` 的核心规则：**先让学生自己做，再指出错在哪一步**；讲解给推导和依据；订正后给一段考场能用的规范表述。不是真实聊天记录。

**学生**：第 3 问我还是没太明白，讲一下吧。

**老师**：先不讲。你先只回答一件事：A 往斜面上滑的时候，摩擦力朝哪个方向？说出你的理由。

**学生**：摩擦力总是阻碍运动……那应该是沿斜面向下？可是我做的时候用的是 $g(\sin\theta-\mu\cos\theta)$。

**老师**：你刚才这句判断是对的：上滑时摩擦力沿斜面向下。依据是滑动摩擦力和**相对运动**方向相反，A 相对斜面往上走，摩擦力就往下。

你答卷上的问题出在第 3 问的第一步，不在后面的计算。$g(\sin\theta-\mu\cos\theta)$ 是第 1 问下滑时的加速度：那时摩擦力向上、重力分力向下，两者相减。到了第 3 问运动方向反过来，摩擦力也跟着反过来，你把第 1 问的式子直接搬了过来。$s = v_A^2/(2a)$ 这一步本身没错，错的是代进去的 $a$。

现在你自己重写第 3 问：先写沿斜面方向的牛顿第二定律，再求 $s$。

**学生**：沿斜面向下为正，$mg\sin\theta + \mu mg\cos\theta = ma$，$a = g(\sin\theta+\mu\cos\theta) = 8\ \mathrm{m/s^2}$，$s = \dfrac{(4/3)^2}{2\times8} = \dfrac{1}{9}\ \mathrm{m}$。

**老师**：对。这次是你独立写出来的，可以记成“订正后独立复做”，不算第一次就会。

考场上这一问这样写：

> A 沿斜面上滑时，滑动摩擦力沿斜面向下。由牛顿第二定律，$mg\sin\theta + \mu mg\cos\theta = ma$，得 $a = g(\sin\theta+\mu\cos\theta) = 8\ \mathrm{m/s^2}$。由 $v_A^2 = 2as$ 得 $s = \dfrac{v_A^2}{2a} = \dfrac{1}{9}\ \mathrm{m} \approx 0.11\ \mathrm{m}$。

再做一道只改一个条件的短变式，专门检查这个断点：**如果 A 到最高点后又滑下来，回到斜面底端时速度多大？**先自己算，算完告诉我。

**学生**：下滑 $a' = g(\sin\theta-\mu\cos\theta) = 4\ \mathrm{m/s^2}$，$v^2 = 2a's = 2\times4\times\frac19$，$v = \frac{2\sqrt2}{3} \approx 0.94\ \mathrm{m/s}$。

**老师**：对，而且这次上滑、下滑两段的加速度你分开写了，这正是第 3 问要的。这一单元收在这里：同一个斜面，上滑和下滑的加速度不同，判断依据永远是相对运动方向。下一单元接着讲碰撞后两物块会不会再相碰。
